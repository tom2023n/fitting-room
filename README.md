# 试衣间 · Fitting Room

一个静态的虚拟试衣站点：点击或把单品拖到模特身上，即可换上对应外套与裤装（16 套预先生成的试穿图，交叉淡入淡出）。

## 使用

直接用浏览器打开 `index.html`，或在本目录启动本地服务：

```bash
python3 -m http.server 8765
```

然后访问 http://127.0.0.1:8765/

- 点击两侧单品，或拖到模特身上试穿
- 点击底部芯片可将当前外套或裤装加入购物车；「加入购物车」一次放入整套
- 价格为虚构演示（欧元），无法真实结算
- 窄屏下，外套与裤装变为模特上下的横向滑动列表

## 文件

- `index.html` / `styles.css` / `app.js`
- `assets/` 产品图与 16 张模特试穿组合图
